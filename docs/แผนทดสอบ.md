## รอบ 3 · เบิกของ

1. **B** มือถือ — เบิกสิ้นเปลือง 2–3 รายการ
2. **คุณ** คอม — **คำขอเบิก** → อนุมัติ → เช็คว่าสต็อกลดจริงที่ **สต็อกวัสดุ**
3. **B** มือถือ — เบิก **Power Pallet** (ถ่าย 5 รูปตามขั้นตอน คีย์ → หน้า → หลัง → ซ้าย → ขวา)
4. **C** มือถือ — **ส่งบาร์โค้ดจาก BY** ถ่ายรูปบาร์โค้ด + ใส่เหตุผล
5. **คุณ** คอม — **บาร์โค้ดจาก BY** → ปิดรายการ → เลือกวัสดุ → ตัดสต็อก

### 3.1 ทดสอบกันกดซ้ำ
6. **B** มือถือ — เบิกสิ้นเปลือง แล้ว **กดปุ่มยืนยันรัว ๆ 2–3 ครั้ง**

✅ ต้องได้ **ใบเดียว** และสต็อกลด**รอบเดียว**

### 3.2 ทดสอบเบิกแทน
7. **A** มือถือ — เบิกอุปกรณ์ → ขั้นแรกกด **"เบิกให้คนอื่น"** → เลือก **C**

✅ ของไปค้างชื่อ **C** ไม่ใช่ A
✅ **C** เปิด "คืนของ" เห็นเครื่องนั้น (ทั้งที่ C เบิก Asset เองไม่ได้)
✅ **A** เปิด "คืนของ" เห็นหัวข้อ **"ที่คุณเบิกให้คนอื่น"** แบบดูอย่างเดียว

## รอบ 4 · คืนของ

1. **B** มือถือ — คืนเองตามปกติ (ถ่ายรูปสภาพ)
2. **A** คอม — **Asset ที่ยังไม่คืน** → **"คืนแทน"** ให้ C
3. **A** คอม — กด **"ปิด/ยกเลิก"** ดูในกล่อง

   ✅ **ต้องไม่มีปุ่ม "ยกเลิก — กดผิด"** ให้ A เห็น (มีเฉพาะคุณกับแอดมิน)

4. **คุณ** คอม — ลองทั้งสองปุ่ม ดูความต่าง
   - **ปิดรายการ — ได้ของคืนแล้ว** → บันทึกเป็นการคืน (ไม่มีรูป)
   - **ยกเลิก — กดผิด** → **ลบทิ้ง ไม่บันทึกว่าเคยคืน**
5. **คุณ/A** คอม — **ของค้างคืน** → **"คืนแทน"** สิ้นเปลือง

   ✅ ต้องบอกว่าจะ**บวกสต็อกกลับให้** และสต็อกเพิ่มจริง

## รอบ 5 · โอนเครื่อง (รถแดง)

1. **B** (แผนก X) มือถือ — เบิก Power Pallet **2 เครื่อง**
2. **คุณ** คอม — **ทะเบียนเครื่อง** → หาเครื่องที่ B ถือ → **โอน** → เลือกแผนกของ **C** → ใส่เหตุผล

✅ **B** เห็นแถบ**เหลือง**: "ถูกโอนไปให้แผนก… **ไม่ต้องคืนเครื่องนี้แล้ว**"
✅ **B ยังค้างเครื่องที่สองอยู่** (ตัดเฉพาะเครื่องที่โอน)
✅ **C** เห็นแถบ**ฟ้า**: "มีการโอน…มาให้แผนกคุณ กรุณากดเบิก"

3. **C** กดเบิกเครื่องนั้น → แล้วคืนตามปกติ

✅ **คุณ** เช็คทะเบียนเครื่อง — เครื่อง**กลับไปอยู่แผนก X เอง** (โอนเป็นแค่ชั่วคราว)

## รอบ 6 · ประชุม

1. **ทุกคน** มือถือ — กดไอคอน 📋 บนหัวจอ → ถ่ายเซลฟี่ → ส่ง
2. **B** กดส่งซ้ำอีกรอบภายใน 10 นาที

   ✅ ขึ้นว่า "เช็คอินไปแล้วเมื่อสักครู่" **ไม่นับซ้ำ**

3. **A** คอม — **รายชื่อประชุม** → เลือกทั้งหมด → **ยืนยันเข้าประชุม**

   ✅ **เด้งไปหน้าหลักฐานการเข้าประชุม** เอง และเห็นรายชื่อครบ

4. **A** คอม — **แดชบอร์ดประชุม** → ดูตัวเลข "ไม่เคยเช็คอินเลย"
5. **คุณ** มือถือ — กด 📋 → เลื่อนล่างสุด → **+ นัดใหม่**
   ใส่เรื่อง · วันเวลา · **ใครต้องเข้า = "sup และ lead"** → ประกาศ

   ✅ **ทั้ง 4 คนได้แจ้งเตือนเข้ามือถือ** (ภายใน 5 นาที)
   ✅ ทุกคนกด 📋 เห็นแถบประกาศพร้อมป้ายดำ "ผู้เข้าร่วม: sup และ lead"
