## รอบ 3 · เบิกของ

1. **C** มือถือ — เบิกสิ้นเปลือง 2–3 รายการ
2. **A** คอม — **คำขอเบิก** → อนุมัติ → เช็คว่าสต็อกลดจริงที่ **สต็อกวัสดุ**
3. **C** มือถือ — เบิก **Power Pallet** (ถ่าย 5 รูปตามขั้นตอน คีย์ → หน้า → หลัง → ซ้าย → ขวา)
4. **D** มือถือ — **ส่งบาร์โค้ดจาก BY** ถ่ายรูปบาร์โค้ด + ใส่เหตุผล
5. **A** คอม — **บาร์โค้ดจาก BY** → ปิดรายการ → เลือกวัสดุ → ตัดสต็อก

### 3.1 ทดสอบกันกดซ้ำ
6. **C** มือถือ — เบิกสิ้นเปลือง แล้ว **กดปุ่มยืนยันรัว ๆ 2–3 ครั้ง**

✅ ต้องได้ **ใบเดียว** และสต็อกลด**รอบเดียว**

### 3.2 ทดสอบเบิกแทน
7. **B** มือถือ — เบิกอุปกรณ์ → ขั้นแรกกด **"เบิกให้คนอื่น"** → เลือก **D**

✅ ของไปค้างชื่อ **D** ไม่ใช่ B
✅ **D** เปิด "คืนของ" เห็นเครื่องนั้น (ทั้งที่ D เบิก Asset เองไม่ได้)
✅ **B** เปิด "คืนของ" เห็นหัวข้อ **"ที่คุณเบิกให้คนอื่น"** แบบดูอย่างเดียว

## รอบ 4 · คืนของ

1. **C** มือถือ — คืนเองตามปกติ (ถ่ายรูปสภาพ)
2. **B** คอม — **Asset ที่ยังไม่คืน** → **"คืนแทน"** ให้ D
3. **B** คอม — กด **"ปิด/ยกเลิก"** ดูในกล่อง

   ✅ **ต้องไม่มีปุ่ม "ยกเลิก — กดผิด"** ให้ B เห็น

4. **A** คอม — กด **"ปิด/ยกเลิก"** ในรายการอื่น

   ✅ **A ต้องเห็นปุ่ม "ยกเลิก — กดผิด"** (แอดมินมี ผู้ตรวจสอบไม่มี)

5. **คุณ** คอม — ลองทั้งสองปุ่ม ดูความต่าง
   - **ปิดรายการ — ได้ของคืนแล้ว** → บันทึกเป็นการคืน (ไม่มีรูป)
   - **ยกเลิก — กดผิด** → **ลบทิ้ง ไม่บันทึกว่าเคยคืน**
6. **A** คอม — **ของค้างคืน** → **"คืนแทน"** สิ้นเปลือง

   ✅ ต้องบอกว่าจะ**บวกสต็อกกลับให้** และสต็อกเพิ่มจริง

7. **A** คอม — เปิด **หลักฐานการเบิก-คืน**

   ✅ **A ต้องไม่มีปุ่มลบ** (มีเฉพาะคุณ)

2. **คุณ** คอม — **ทะเบียนเครื่อง** → หาเครื่องที่ C ถือ → **โอน** → เลือกแผนกของ **D** → ใส่เหตุผล

✅ **C** เห็นแถบ**เหลือง**: "ถูกโอนไปให้แผนก… **ไม่ต้องคืนเครื่องนี้แล้ว**"
✅ **C ยังค้างเครื่องที่สองอยู่** (ตัดเฉพาะเครื่องที่โอน)
✅ **D** เห็นแถบ**ฟ้า**: "มีการโอน…มาให้แผนกคุณ กรุณากดเบิก"

✅ **คุณ** เช็คทะเบียนเครื่อง — เครื่อง**กลับไปอยู่แผนก X เอง** (โอนเป็นแค่ชั่วคราว)

4. **B** ลองกดปุ่มโอนดู

✅ **ผู้ตรวจสอบโอนได้** (แต่เปลี่ยนแผนกเจ้าของถาวรไม่ได้ — นั่นของคุณคนเดียว)

## รอบ 6 · ประชุม

   ✅ ขึ้นว่า "เช็คอินไปแล้วเมื่อสักครู่" **ไม่นับซ้ำ**

3. **B** คอม — **รายชื่อประชุม** → เลือกทั้งหมด → **ยืนยันเข้าประชุม**

   ✅ หน้าหลักฐาน**ไม่มีปุ่มนับ/ไม่นับ** — เป็นตารางดูอย่างเดียว

4. **B** คอม — **แดชบอร์ดประชุม** → ดูตัวเลข "ไม่เคยเช็คอินเลย"

   ✅ **ทั้ง 5 คนได้แจ้งเตือนเข้ามือถือ** (ภายใน 5 นาที)
   ✅ ทุกคนกด 📋 เห็นแถบประกาศพร้อมป้ายดำ "ผู้เข้าร่วม: sup และ lead"
