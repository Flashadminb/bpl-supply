ช่องค้นหาตามวันที่ทุกหน้าใน BPL SUPPLY ให้ใช้ `<DateRangePicker>`
(`src/components/DateRangePicker.tsx`) แบบเดียวกับหน้าประวัติเบิก
ห้ามทำเป็นดรอปดาวน์เลือกเดือน/เลือกวัน หรือช่อง `<input type="date">` เปล่า ๆ

**Why:** เจ้าของระบบสั่งไว้ตอนแก้หน้ารายชื่อเข้าประชุม 2026-10-03
ว่า "ต่อไปถ้าอะไรที่เป็นค้นหาตามวันที่ทำแบบนี้หมดนะ" — เขาต้องการให้ทุกหน้าใช้ท่าเดียวกัน
จะได้ไม่ต้องเรียนรู้ใหม่ทีละหน้า

**How to apply:** เจอหน้าไหนที่ยังเป็นดรอปดาวน์วันที่ ให้เปลี่ยนเลยโดยไม่ต้องถาม
และหน้าใหม่ที่มีการกรองตามวัน ให้ใช้ตัวนี้ตั้งแต่แรก
