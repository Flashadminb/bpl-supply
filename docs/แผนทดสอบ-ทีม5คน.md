## รอบ 3 · เบิกของ

1. **C** มือถือ — เบิกสิ้นเปลือง 2–3 รายการ
2. **A** คอม — เข้า **คำขอเบิก** กดอนุมัติ → เช็คว่าสต็อกลดจริงที่หน้า **สต็อกวัสดุ**
3. **C** มือถือ — เบิก **Power Pallet** (ต้องถ่าย 5 รูปตามขั้นตอน คีย์ → หน้า → หลัง → ซ้าย → ขวา)
4. **D** มือถือ — **ส่งบาร์โค้ดจาก BY** ถ่ายรูปบาร์โค้ด + ใส่เหตุผล
5. **A** คอม — เข้า **บาร์โค้ดจาก BY** กดปิดรายการ เลือกวัสดุ ตัดสต็อก

### ทดสอบกันกดซ้ำ
6. **C** มือถือ — เบิกสิ้นเปลือง แล้ว **กดปุ่มยืนยันรัว ๆ 2–3 ครั้ง**
   ✅ ต้องได้ **ใบเดียว** และสต็อกลดรอบเดียว

### ทดสอบเบิกแทน
7. **B** มือถือ — เบิกอุปกรณ์ → ขั้นแรกกด **"เบิกให้คนอื่น"** → เลือก **D**
   ✅ ของต้องไปค้างชื่อ **D** ไม่ใช่ B
   ✅ **D** เปิดหน้า "คืนของ" ต้องเห็นเครื่องนั้น
   ✅ **B** เปิดหน้า "คืนของ" ต้องเห็นหัวข้อ **"ที่คุณเบิกให้คนอื่น"** แบบดูอย่างเดียว

## รอบ 4 · คืนของ

1. **C** มือถือ — คืนเองตามปกติ (ถ่ายรูปสภาพ)
2. **B** คอม — เข้า **Asset ที่ยังไม่คืน** กด **"คืนแทน"** ให้ D
3. **คุณ** คอม — ลองปุ่ม **"ปิด/ยกเลิก"** ดูความต่าง:
   - **ปิดรายการ — ได้ของคืนแล้ว** → บันทึกเป็นการคืน (ไม่มีรูป)
   - **ยกเลิก — กดผิด** → **ลบทิ้ง ไม่บันทึกว่าเคยคืน**
4. **B** คอม — ลองกด "ยกเลิก — กดผิด"
   ✅ **ต้องไม่มีปุ่มนี้ให้ B เห็น** (ลบได้เฉพาะคุณกับ A)
5. **คุณ/A** คอม — เข้า **ของค้างคืน** กด **"คืนแทน"** สิ้นเปลือง
   ✅ ต้องมีข้อความว่าจะ**บวกสต็อกกลับให้** และสต็อกเพิ่มจริง

## รอบ 5 · โอนเครื่อง (รถแดง)

1. **C** (แผนก X) มือถือ — เบิก Power Pallet ไว้ 2 เครื่อง
2. **คุณ** คอม — **ทะเบียนเครื่อง** → หาเครื่องที่ C ถือ → กด **โอน** → เลือกแผนกของ **D** → ใส่เหตุผล
3. ✅ **C** ต้องเห็นแถบ**เหลือง**: "ถูกโอนไปให้แผนก… **ไม่ต้องคืนเครื่องนี้แล้ว**"
4. ✅ **C** ต้องยัง**ค้างเครื่องที่สอง**อยู่ (ตัดเฉพาะเครื่องที่โอน)
5. ✅ **D** ต้องเห็นแถบ**ฟ้า**: "มีการโอน…มาให้แผนกคุณ กรุณากดเบิก"
6. **D** กดเบิกเครื่องนั้น → แล้วคืนตามปกติ
7. ✅ **คุณ** เช็คที่ทะเบียนเครื่อง — เครื่องต้อง**กลับไปอยู่แผนก X เอง** (โอนเป็นแค่ชั่วคราว)

## รอบ 6 · ประชุม

1. **ทุกคน** มือถือ — กดไอคอน 📋 บนหัวจอ → ถ่ายเซลฟี่ → ส่ง
2. **C** ลองกดส่งซ้ำอีกรอบภายใน 10 นาที
   ✅ ต้องขึ้นว่า "เช็คอินไปแล้วเมื่อสักครู่" ไม่นับซ้ำ
3. **B** คอม — **รายชื่อประชุม** → เลือกทั้งหมด → **ยืนยันเข้าประชุม**
   ✅ ต้องเด้งไปหน้า **หลักฐานการเข้าประชุม** และเห็นรายชื่อครบ
4. **B** คอม — **แดชบอร์ดประชุม** → เช็คตัวเลข "ไม่เคยเช็คอินเลย"
5. **คุณ/B** มือถือ — กด 📋 → เลื่อนล่างสุด → **+ นัดใหม่**
   ใส่เรื่อง วันเวลา และ **ใครต้องเข้า = "sup และ lead"** → ประกาศ
   ✅ **ทั้ง 5 คนต้องได้แจ้งเตือนเข้ามือถือภายใน 10 วินาที**
   ✅ ทุกคนกด 📋 ต้องเห็นแถบประกาศพร้อมป้ายดำ "ผู้เข้าร่วม: sup และ lead"
