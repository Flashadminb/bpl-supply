# BPL SUPPLY — สเปกระบบเบิก–คืนวัสดุสิ้นเปลือง

เวอร์ชัน 1.0 · 22 ก.ย. 2569 · สำหรับ Flash Express BPL HUB (รองรับหลายฮับ: BPL, AYU, PDT, WNO, BAG)

---

## 1. ภาพรวม

พนักงานหน้างานเบิกวัสดุสิ้นเปลือง (น้ำยาล้างห้องน้ำ ผงซักฟอก ไม้กวาด ถุงมือ ฯลฯ) ผ่านมือถือ
สแกน QR ที่ชั้นวางหรือเลือกจากรายการ ใส่ตะกร้าได้หลายรายการ ถ่ายรูปหลักฐาน 1 รูป แล้วยืนยันครั้งเดียว
ระบบตัดสต็อกทุกบรรทัดใน transaction เดียว เก็บรูปไว้ที่ Google Drive และสรุปลง Google Sheet

**เป้าหมาย:** ต้นทุน 0 บาท ใช้ฟรีเทียร์ทั้งหมด · พนักงานเบิกเสร็จใน 30 วินาที · แอดมินตรวจย้อนหลังได้ทุกรายการพร้อมรูป

### บทบาทผู้ใช้

| บทบาท | ทำอะไรได้ |
|---|---|
| `staff` | เบิก/คืนวัสดุ ดูประวัติของตัวเอง |
| `supervisor` | ของ staff + ดูประวัติทั้งฮับ + อนุมัติคำขอ |
| `admin` | ทั้งหมด + แก้สต็อก + จัดการผู้ใช้ + ส่งออก Google Sheet |

## 2. สถาปัตยกรรม

```
มือถือพนักงาน (PWA บน Cloudflare Pages)
   │
   ├─ 1. ถ่ายรูป → ย่อเป็น WebP ด้านยาว 1024px ในเครื่อง (canvas)
   │
   ├─ 2. POST blob ──► Edge Function `upload-evidence`
   │                      └─► Google Drive API (service account)
   │                          คืน { fileId, webViewLink }
   │
   ├─ 3. RPC `create_requisition` ──► Postgres
   │        เขียน requisitions 1 แถว + requisition_items N แถว
   │        ล็อกแถว items FOR UPDATE แล้วตัดสต็อกทุกบรรทัด
   │        ล้มทั้งชุดถ้าบรรทัดใดสต็อกไม่พอ
   │
   ├─ 4. ลบ blob / revoke object URL ในเครื่อง
   │
   └─ 5. (ตามรอบหรือกดเอง) Edge Function `export-sheet`
            └─► Google Sheets API — 1 แถวต่อ 1 รายการวัสดุ
                คอลัมน์หลักฐานเป็น =HYPERLINK(driveLink; "ดูรูป")
```

### ตัวแปรสภาพแวดล้อม

**ฝั่ง client (`.env`)**
```
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

**ฝั่ง Edge Function (Supabase secrets) — ห้ามอยู่ในฝั่ง client**
```
GOOGLE_SA_EMAIL=            # service account email
GOOGLE_SA_PRIVATE_KEY=      # private key แบบ PEM
GDRIVE_FOLDER_ID=           # โฟลเดอร์ปลายทางใน Shared Drive
GSHEET_ID=                  # ไอดีของ Google Sheet ปลายทาง
GSHEET_TAB=บันทึกการเบิก-คืน
```

> ต้องแชร์ทั้งโฟลเดอร์ Drive และ Sheet ให้อีเมล service account สิทธิ์ Editor ก่อน
> ถ้าใช้ Shared Drive ให้ใส่ `supportsAllDrives=true` ตอนเรียก Drive API

## 3. โครงข้อมูล

รายละเอียดเต็มอยู่ใน `schema.sql` สรุปตารางหลัก:

| ตาราง | เก็บอะไร |
|---|---|
| `hubs` | รหัสและชื่อฮับ |
| `profiles` | ผู้ใช้ ผูกกับ `auth.users` — รหัสพนักงาน ชื่อ ฮับ บทบาท สถานะ |
| `categories` | หมวดวัสดุ + ธงว่าหมวดนี้อนุมัติอัตโนมัติได้ไหม |
| `items` | วัสดุ — SKU ชื่อ หน่วย ชั้นวาง สต็อกคงเหลือ ขั้นต่ำ ประเภทยืม-คืน รหัส QR |
| `requisitions` | หัวคำขอ — เลขที่ ผู้เบิก ฮับ วัตถุประสงค์ สถานะ รูปหลักฐาน |
| `requisition_items` | บรรทัดรายการ — จำนวนที่ขอ จำนวนที่อนุมัติ สต็อกก่อน/หลัง |
| `returns` | การคืนของประเภทยืม-คืน — จำนวน สภาพ รูปตอนคืน |
| `stock_movements` | ประวัติการเคลื่อนไหวสต็อกทุกครั้ง (audit trail) |
| `sync_log` | สถานะการซิงค์รายคำขอ ใช้เติมแถบรหัสย่อ IMG/GDV/SPB/TMP/GSH |
| `app_settings` | ค่าตั้งระบบ เช่น เปิด/ปิดอนุมัติอัตโนมัติ |

### สถานะคำขอ

`pending` รออนุมัติ → `approved` อนุมัติทั้งหมด · `partial` อนุมัติบางรายการ · `rejected` ปฏิเสธ

### กติกาอนุมัติอัตโนมัติ

ถ้า `app_settings.auto_approve_consumables = true` **และ** ทุกบรรทัดอยู่ในหมวดที่ `auto_approvable = true`
**และ** ไม่มีบรรทัดไหนทำให้สต็อกต่ำกว่าขั้นต่ำ → อนุมัติทันที ตัดสต็อกเลย
นอกนั้นเข้าคิวรออนุมัติ และ**ยังไม่ตัดสต็อก** จนกว่าแอดมินจะกดอนุมัติ

## 4. หน้าจอฝั่งพนักงาน (มือถือ 390×844)

### 4.1 เข้าสู่ระบบ
รหัสพนักงาน + รหัสผ่าน · จำฉันไว้ · ลืมรหัสผ่าน · ทางเลือกเข้าระบบด้วย QR บัตรพนักงาน · แบนเนอร์เชิญติดตั้ง PWA

### 4.2 หน้าหลัก
ทักทายพร้อมชื่อ ฮับ บทบาท · ปุ่มใหญ่ "สแกน QR เพื่อเบิก" · การ์ดคู่ เบิกวัสดุ / คืนวัสดุ (โชว์จำนวนค้างคืน) · การ์ดตะกร้าค้าง (ถ้ามี) · รายการล่าสุด 3 รายการพร้อมป้ายสถานะ · แถบเมนูล่าง 4 ปุ่ม

### 4.3 สแกน QR
กล้องเต็มจอ กรอบเล็ง เปิดไฟฉาย ป้อนรหัสเอง · **สแกนต่อเนื่องได้** ทุกชิ้นไปรวมตะกร้าเดียว
เจอของแล้วเด้ง bottom sheet: ชื่อ ชั้นวาง คงเหลือ ปรับจำนวน แล้วเลือก "ใส่ตะกร้า · สแกนต่อ" หรือ "ดูตะกร้า"

### 4.4 รายการวัสดุ
ค้นหา · ชิปกรองหมวด · แต่ละแถวมีปุ่ม `+` ใส่ตะกร้าในตัว รายการที่ใส่แล้วแสดงตัวนับ −/+
ของใกล้หมดขึ้นป้ายเหลือง ของหมดสต็อกจางลงและกดไม่ได้ (มีปุ่มแจ้งเตือนเมื่อของเข้า)
ล่างสุดมีแถบตะกร้าลอยแสดงจำนวนรายการและชิ้นรวม

### 4.5 รายละเอียดรายการ
รูป ชื่อ SKU ชั้นวาง คงเหลือ · ปรับจำนวนพร้อมปุ่มลัด 1/3/5 และคำนวณคงเหลือหลังเบิก · วัตถุประสงค์ · หมายเหตุ
ปุ่ม "เพิ่มลงตะกร้า" กับ "เลือกต่อ"

### 4.6 ตะกร้าเบิก
ทุกรายการในคำขอ แก้จำนวน/ลบได้รายบรรทัด · ปุ่มสแกนเพิ่ม/เลือกเพิ่ม · วัตถุประสงค์ใช้ร่วมทั้งคำขอ
แจ้งว่าถ่ายรูป 1 รูปครอบทุกรายการ · ยอดรวมท้ายหน้า · ปุ่มไปถ่ายรูป
**ตะกร้าต้องเก็บใน localStorage** ปิดแอปแล้วกลับมาต้องยังอยู่

### 4.7 ถ่ายรูปหลักฐาน
พรีวิวรูป · ขนาดหลังบีบอัดและความละเอียด · ชิปบอกว่าครอบรายการไหนบ้าง · ปุ่มถ่ายแยกรายรายการ (ทางเลือก)
แถบรหัสสถานะย่อ · ปุ่มถ่ายใหม่ / ยืนยัน

### 4.8 เบิกสำเร็จ
เครื่องหมายถูกใหญ่ · เลขที่คำขอ · รายการทั้งหมดพร้อมสต็อกคงเหลือรายบรรทัด · ผู้เบิก เวลา สถานะ
แถบรหัสสถานะย่อ (ไม่มีลิงก์เปิดรูป) · ปุ่มเบิกต่อ / กลับหน้าหลัก

### 4.9 คืนวัสดุ
เฉพาะของประเภทยืม-คืนที่ยังไม่ได้คืน · เลือกรายการ จำนวนคืน สภาพ (ใช้ได้/ชำรุด/สูญหาย) · ถ่ายรูปสภาพตอนคืน

### 4.10 ประวัติ
กรอง ทั้งหมด/รออนุมัติ/อนุมัติแล้ว/คืนแล้ว · จัดกลุ่มตามวัน
แต่ละคำขอแสดงเลขที่ จำนวนรายการ ชิ้นรวม และบรรทัดย่อยทั้งหมด · แถบรหัสสถานะย่อ **ไม่มีลิงก์เปิดรูป**

## 5. หน้าจอฝั่งแอดมิน (เดสก์ท็อป 1280×880)

แถบข้างซ้าย 244px พื้นเข้ม เมนู: ภาพรวม · สต็อกวัสดุ · คำขอเบิก (มี badge) · ผู้ใช้และสิทธิ์ · ส่งออก Google Sheet

### 5.1 ภาพรวม
การ์ดตัวเลข 4 ช่อง: เบิกวันนี้ · รออนุมัติ (พร้อมอายุคำขอเก่าสุด) · วัสดุต่ำกว่าขั้นต่ำ · ค้างคืน
ตารางรายการเบิกล่าสุดพร้อมลิงก์เปิดรูป · รายการต้องสั่งซื้อเพิ่ม · สถานะการเชื่อมต่อ Sheet/Drive/Supabase
ปุ่ม "ส่งข้อมูลลง Google Sheet" มุมขวาบน

### 5.2 สต็อกวัสดุ
ตาราง: วัสดุ SKU หมวด ชั้นวาง คงเหลือ ขั้นต่ำ สถานะ จัดการ
ชิปกรอง: ทั้งหมด / ใกล้หมด / หมดสต็อก / ประเภทยืม-คืน · ปุ่มเพิ่มวัสดุ · ปุ่มพิมพ์ QR

### 5.3 อนุมัติคำขอ
ซ้าย: คิวคำขอ แต่ละใบบอกเลขที่ จำนวนรายการ ผู้ขอ เวลา
ขวา: รายละเอียดคำขอ — รูปหลักฐาน (เปิดใน Drive ได้), **ตารางบรรทัดรายการพร้อมเช็กบ็อกซ์** แสดงจำนวนขอและสต็อกก่อน→หลัง
บรรทัดที่จะทำให้ต่ำกว่าขั้นต่ำขึ้นสีแดงพร้อมคำเตือน
ปุ่ม: ปฏิเสธทั้งคำขอ / แก้ไขจำนวน / **อนุมัติเฉพาะรายการที่เลือก** (อนุมัติบางส่วน → สถานะ `partial`)
สวิตช์อนุมัติอัตโนมัติสำหรับของสิ้นเปลืองอยู่บนหัวหน้า

### 5.4 ผู้ใช้และสิทธิ์
ตารางบัญชี: ชื่อ รหัสพนักงาน ฮับ บทบาท สถานะ · ตารางสิทธิ์ RBAC 3 บทบาทข้าง ๆ

### 5.5 ส่งออก Google Sheet
เลือกช่วงเวลา ฮับ ปลายทาง Sheet และคอลัมน์ที่ต้องส่ง · ตัวอย่างข้อมูลก่อนส่ง · ประวัติการส่ง · สูตร HYPERLINK ที่ใช้
สถานะ service account แสดงบนหัวหน้า

### 5.6 แอดมินบนมือถือ (390px)
การ์ดตัวเลข 3 ช่อง · คิวอนุมัติด่วนพร้อมปุ่มอนุมัติ/ปฏิเสธในตัว · ปุ่มส่ง Google Sheet

## 6. Google Sheet ที่ส่งออก

หนึ่งแถวต่อหนึ่งรายการวัสดุ คำขอที่เบิกหลายอย่างใช้เลขที่เดียวกันหลายแถว

| คอลัมน์ | ข้อมูล |
|---|---|
| A | เลขที่คำขอ (`REQ-2026-0912`) |
| B | วันเวลา |
| C | ผู้เบิก (ฮับ) |
| D | วัสดุ |
| E | จำนวน |
| F | หลักฐาน — `=HYPERLINK("https://drive.google.com/file/d/<FILE_ID>/view"; "ดูรูป")` |
| G | Drive File ID (ตัวเลือก) |

ส่งซ้ำได้โดยไม่เกิดแถวซ้ำ — ใช้คู่ `(requisition_ref, item_sku)` เป็นกุญแจ แล้ว upsert
